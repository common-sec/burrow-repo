# Security

Report vulnerabilities in the presets, their images or the publish pipeline the same way as for
burrow: see [burrow-sandbox's SECURITY.md](https://github.com/common-sec/burrow-sandbox/blob/main/SECURITY.md).
A published version found to be unsafe is yanked (`YANKED`, [docs/CONTRACT.md](docs/CONTRACT.md)
section 7) and fixed by a new revision.
